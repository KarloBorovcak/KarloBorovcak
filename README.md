# Karlo Borovčak

AI engineer at [Lebesgue](https://lebesgue.io) in Zagreb. I build AI agents for e-commerce brands and for our in-house ads team.

What I've built there:

- [Henri](https://lebesgue.io/product-features/henri-ai-agent-for-growth), an AI analyst used by 400+ e-commerce merchants. A LangGraph multi-agent system with sub-agents for Google Ads, Meta Ads, Klaviyo and Google Analytics, Python and SQL execution in Daytona sandboxes, and LangSmith tracing.
- The Lebesgue MCP server, so merchants can ask Claude or ChatGPT about their store and ad data. OAuth 2.1 login, text-to-SQL over ClickHouse and PostgreSQL.
- An AI agent for our managed-ads team, shipped as a Claude and Codex plugin. It pulls data from Lebesgue, Google Ads, Meta Ads and Klaviyo and keeps notes on each client brand.
- The move of our pixel analytics warehouse from Redshift to ClickHouse, over a billion events.
- Integrations with Amazon Seller, Amazon Ads, Klaviyo and Google Ads on FastAPI, Celery and AWS ECS.

That code is private. The public repos here are older: an audio instrument classifier from Lumen Data Science 2023, and my bachelor thesis on predicting the NCAA March Madness tournament.

Python · LangGraph · MCP · FastAPI · ClickHouse · PostgreSQL · TypeScript · Next.js · AWS
